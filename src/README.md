# AMI Florería Landing Page

## Overview
This project is dedicated to creating a premium landing page for "AMI", a local flower shop located in Hermosillo, Sonora. The landing page aims to provide an engaging and visually appealing experience for potential customers, showcasing the shop's offerings and encouraging conversions.

## Project Structure
The project is organized as follows:

- **index.html**: The main structure of the landing page, featuring sections for the hero, products, services, testimonials, FAQ, and footer.
- **assets/**: Contains the logo and other images that represent the brand.
  - **logo.svg**: The logo of AMI, used throughout the landing page.
- **css/**: Custom styles for the landing page.
  - **styles.css**: Styles that ensure a visually appealing design aligned with the brand's identity.
- **js/**: Handles interactivity on the landing page.
  - **main.js**: Manages WhatsApp integration and dynamic content updates.
- **referencias-para-construir/**: A folder for visual references, including design elements that inform the landing page's aesthetic.
- **business-plan.md**: Outlines the strategic and creative plan for the landing page, detailing structure, color palette, copywriting, and overall design approach.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the `ami-floreria` directory.
3. Open `index.html` in your preferred web browser to view the landing page.
4. Customize the styles in `css/styles.css` and the interactivity in `js/main.js` as needed.

## Features
- **Hero Section**: Captivating introduction to AMI with a call-to-action.
- **Products Section**: Showcase of available floral arrangements and gifts.
- **Services Section**: Information on delivery options and custom arrangements.
- **Testimonials**: Customer reviews to build trust and credibility.
- **FAQ Section**: Answers to common questions to assist potential customers.
- **Footer**: Contact information and social media links for easy access.

This README serves as a guide for understanding the project structure and how to set up and customize the landing page for AMI Florería.
